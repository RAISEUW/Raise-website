    ```bash
    node -e 'const r=require("./.planning/phases/03-cms-production-launch/03-03-LIGHTHOUSE.report.json");for(const k of ["performance","accessibility","best-practices","seo"])console.log(k, Math.round(r.categories[k].score*100))'
    ```

    **Step 3: If any category < 95, diagnose and fix.** Common fixes (in order of usual impact for a static Astro site):

    - **Performance < 95**:
      - Add `width` and `height` to all `<img>` tags to prevent CLS (grep `<img ` across src/ — Astro warns on missing dimensions).
      - Use Astro's `<Image>` component from `astro:assets` for any hero image (auto format + resize + lazy).
      - Preload the critical Fraunces font variant (currently only a stylesheet link, not a preload):
        ```astro
        <link rel="preload" as="font" type="font/woff2" crossorigin href="https://fonts.gstatic.com/s/fraunces/v..." />
        ```
        (Only if font FCP is the bottleneck — verify via Lighthouse audit details.)
      - Ensure no render-blocking third-party scripts loading on the homepage.

    - **Accessibility < 95**:
      - Every `<img>` needs `alt`. Every `<a>` must have discernible text. Color contrast >= 4.5:1 for body text.
      - `<html lang="en">` (already set in Base.astro line 23 — verify preserved).
      - Form labels properly associated (already done in get-involved.astro — skip unless flagged).

    - **Best Practices < 95**:
      - No console errors (open DevTools console on homepage — should be clean).
      - HTTPS (Cloudflare Pages serves HTTPS by default — should be fine).
      - `<meta name="viewport">` (already set — verify preserved).

    - **SEO < 95**:
      - Meta description present on homepage (Base.astro line 28 — already set; verify homepage passes a description prop).
      - Canonical link (already set — verify).
      - robots.txt present (check dist/robots.txt — if missing, create site/public/robots.txt with `User-agent: *\nAllow: /\nSitemap: https://raise.uw.edu/sitemap-index.xml` — though sitemap requires the astro-sitemap integration; if not installed, just the User-agent+Allow lines are fine).
