    ```
    # Legacy WordPress URL redirects (per D-11)
    /talksevents/*           /events          301
    /people/*                /people          301
    /publications/*          /publications    301
    ```

    Notes:
    - `/talksevents/*` catches both `/talksevents/` and any sub-URLs like `/talksevents/ai-ageism-studying-age-discrimination-in/`.
    - `/people/*` and `/publications/*` are catch-alls — individual old slugs redirect to the index (per D-11: individual old post URLs not covered above gracefully 404 — and these catch-alls bring them to the index instead).
    - Each line: 3 whitespace-separated tokens. Exact file path: `site/public/_redirects` (no extension).
    - Astro copies `public/` verbatim to `dist/` at build, so `dist/_redirects` will exist post-build — Cloudflare Pages reads it at that location.

    Do NOT add redirects for `/admin*` (Decap CMS lives there — must serve normally), `/rss.xml` (feed must serve), or other live routes.
