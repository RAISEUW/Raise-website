# Hero artwork provenance

The publication hero backgrounds were generated specifically for the RAISE website using OpenAI image generation. No stock imagery, third-party source images, logos, or artist references were used. The active set shares a tactile paper, brass, ink, and aubergine editorial language.

All prompts requested original, logo-free, text-free artwork in a shared RAISE palette. Keep this file with the images so their origin remains clear during future site maintenance.
